# CANVAULT 1.9.3

CANVAULT 1.9.3 introduces the new app identity across Android, iOS, launch screens, and in-app branding. This release also adds the first complete native SwiftUI project alongside the maintained Android app.

## Highlights

- New CANVAULT logo and app icon throughout the project
- Native iOS 16+ SwiftUI app with inventory, scanner, Color Combo, market, archive, history, statistics, photos, CSV sharing, sounds, and haptics
- Shared catalog with 1,876 manufacturer colors, 19 verified barcode products, 31 price analyses, and 23 documented sources
- In-app barcode scanning and locally learned barcode matches on both platforms
- Android version updated to 1.9.3 (build 23)
- iOS version prepared as 1.9.3 (build 23)
- Automated iOS simulator build check through GitHub Actions

## iOS status

The complete Xcode source project is included under `native-ios`. Installing it on an iPhone requires Xcode on macOS, an Apple ID, and code signing. An installable iOS package is not included in this GitHub release.
